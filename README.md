# Airport Express — reproducible code

Public repository for the analysis and forecasting experiments:

- `code/`: analysis and editorial Python scripts, dependencies, inference examples and saved results.
- `dataset/`: 32 pinned Excel inputs, verified against `code/source_manifest.json`.

See [code/README.md](code/README.md) for the reproducibility commands.
The manuscript, bibliography, publication figures and LaTeX tables are maintained
separately in the private `paper-airport-express-text` repository. All code lives
here; editorial scripts read and write paper assets in that sibling repository.
Running the analysis does not require access to the private repository.
